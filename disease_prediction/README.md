# Disease Prediction

A machine learning web application developed as part of my CodeAlpha internship.

## Features

The application provides prediction modules for:

- Heart Disease
- Diabetes
- Breast Cancer

## Machine Learning Algorithms

- Logistic Regression
- Support Vector Machine (SVM)
- Random Forest
- XGBoost

## Technologies Used

- Python
- Streamlit
- Pandas
- NumPy
- Scikit-learn
- XGBoost

## How to Run

1. Install the required libraries:

   `pip install -r requirements.txt`

2. Start the application:

   `streamlit run app.py`

## Note

This project is intended for educational purposes. Its predictions are not a substitute for professional medical diagnosis.
